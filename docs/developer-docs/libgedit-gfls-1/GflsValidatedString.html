Description

A string after a pass (or several passes) of validation.

The use-case for GflsValidatedString is when you have raw data that must be validated before being used elsewhere (for example, to insert it into a GtkTextBuffer). The initially invalid regions in the data have been made valid and are marked as such by having separate GflsValidatedStringChunk's. See gfls_validated_string_chunk_get_valid().

Each chunk is also nul-terminated.
