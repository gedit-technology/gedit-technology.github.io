Description

A utility class to convert from one character encoding to another.

A GflsEncodingConverter object can be used only for one conversion. Call the functions in this order:

  • gfls_encoding_converter_new()

  • gfls_encoding_converter_set_allow_invalid_bytes()

  • gfls_encoding_converter_set_callback() to get the output.

  • gfls_encoding_converter_open()

  • gfls_encoding_converter_feed(), several times if streaming is desired.

  • gfls_encoding_converter_finish_feeding()

  • Finally gfls_encoding_converter_get_lossy_conversion() can be called to know more about how the conversion was performed.

GflsEncodingConverterCallback ()

void
(*GflsEncodingConverterCallback) (GBytes *bytes,
                                  gboolean is_valid,
                                  gpointer user_data);

This callback function is called when there is an output chunk from the GflsEncodingConverter.

bytes is always nul-terminated, but this is not included in the GBytes length.

If is_valid is TRUE, the chunk has been successfully converted.

If is_valid is FALSE, the bytes is a copy of the input bytes for which the conversion failed. Note especially that the bytes have not been escaped; for that, you can call a function like gfls_utils_bytes_to_hex_representation().

GflsEncodingConverter makes no attempts to coalesce contiguous chunks of the same kind. In other words, this callback can be called many times in a row with the same value for is_valid .

You need to either use bytes directly during the call of this callback, or increase the reference count to store bytes for later use. (When the call of the callback finishes, GflsEncodingConverter decreases the reference count of bytes ).

bytes

the chunk data.

  

is_valid

whether bytes is a valid chunk.
