libgedit-gfls Introduction

libgedit-gfls is part of Gedit Technology.

It is a library that extends GLib/GIO for text editors needs. Note that it only contains backend features, the frontend parts are implemented by other libgedit-* modules. As such, libgedit-gfls can be used for both GTK 3 and GTK 4 (for examples).

“Gfls” initially was the acronym for “GLib-based File Loading and Saving”, since loading and saving documents in gedit involves a good chunk of code. But nowadays, libgedit-gfls should just be seen as a “libgedit-glib-extras” that extends GLib/GObject/GIO with more features useful for gedit and related apps.

pkg-config name

For libgedit-gfls 1, the pkg-config name is: libgedit-gfls-1

To compile a program that uses libgedit-gfls 1, you can for example use the following command:

$ gcc hello.c `pkg-config --cflags --libs libgedit-gfls-1` -o hello
