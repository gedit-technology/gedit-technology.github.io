gtex_projects_add_project ()

gboolean
gtex_projects_add_project (GtexProjects *projects,
                           GtexProject *project_to_add,
                           GtexProject **conflict_project);

Tries to add project_to_add to projects .

If project_to_add is in conflict with a project already present in projects , FALSE is returned and conflict_project is set.

Parameters

projects

the GtexProjects instance.

  

project_to_add

a new GtexProject.

  

conflict_project

returns the GtexProject already part of projects which is in conflict with project_to_add .

[out][transfer full][nullable][optional]

Returns

TRUE if and only if the project_to_add has been successfully added.
