gtex_project_conflict ()

gboolean
gtex_project_conflict (GtexProject *project1,
                       GtexProject *project2);

Checks the projects' directories. There are no concepts of sub-projects, so there is a conflict when a project is inside another, or when their directories are equal.

If project1 and project2 reference the same GtexProject object, FALSE is returned.

Parameters

project1

a GtexProject.

  

project2

a GtexProject.

  

Returns

whether both projects are in conflict.
