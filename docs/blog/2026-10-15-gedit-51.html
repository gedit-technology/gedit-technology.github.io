2026-10-15: gedit 51.0 released

The gedit text editor version 51 has been released!

A previous blog post, News, April-May 2026 already covers most of the changes.

A reminder that gedit is still alive and is available to install, as an alternative.

Progress has been made since May, but it's mostly under-the-hood changes, preparatory work to replace some internals and eventually make bigger visible changes to the application(s).

B2B Services

gedit is not only an application, there is a set of libgedit-* shared libraries underneath. This collection of re-usable code can be leveraged to create new products, and B2B services are possible.

This was another reminder, but it cannot hurt ;-)
